# Создание чат-бота на основе Rasa

В данном репозитории представлен пример создания NLU чат-бота на основе Rasa, который может обрабатывать запросы
пользователей и предоставлять базовые ответы. Проект состоит из backend-а, представляющего собой API обученной модели,
и frontend-а, который позволяет взаимодействовать с ней через веб-интерфейс.

## Запуск

Сначала необходимо обучить модель Rasa.
Для этого установите окружение и запустите `rasa train` в директории `backend/rasa`.
После обучения запустите сервер Rasa:

```shell
rasa run --enable-api --cors "*"
```

Затем запустите веб-интерфейс в директории `frontend`:

```shell
pnpm run start
```

Лог сервера Rasa можно посмотреть в [`backend/rasa/access.log`](backend/rasa/access.log).
